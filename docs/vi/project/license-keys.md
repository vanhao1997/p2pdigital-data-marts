---
title: License keys
description: Quản lý license key và theo dõi consumption.
---

Chỉ admin nên tạo hoặc rotate license key. Lưu key trong secret manager, đặt expiry nếu có, và revoke key cũ sau khi xác nhận integration mới hoạt động. Đối chiếu usage với Run History khi consumption không khớp.
