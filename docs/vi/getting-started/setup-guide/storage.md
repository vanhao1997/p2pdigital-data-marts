---
title: Hướng dẫn Kho lưu trữ
description: Kết nối và quản lý Kho lưu trữ dữ liệu cho dự án P2PDigital.
---

1. Mở **Dữ liệu → Kho lưu trữ**.
2. Chọn nền tảng, ví dụ Google BigQuery, Snowflake, Databricks, AWS Athena hoặc AWS Redshift.
3. Nhập thông tin kết nối và bí mật theo hướng dẫn của nền tảng.
4. Kiểm tra kết nối trước khi lưu.
5. Gán Kho lưu trữ cho Data Mart phù hợp.

Không đưa khóa truy cập hoặc Service Account JSON vào tài liệu, Git hoặc ảnh chụp màn hình. Xem [danh sách Kho lưu trữ được hỗ trợ](https://docs.p2pdigital.io.vn/docs/storages/manage-storages/).
