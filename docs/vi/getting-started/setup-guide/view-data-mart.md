title: Data Mart từ view
description: Đọc dữ liệu đã được đóng gói trong database view.
---

Chọn view có quyền đọc ổn định, xác nhận owner và schema trả về, sau đó chạy preview. View phụ thuộc vào query nguồn; hãy kiểm tra dependency khi schema thay đổi và chạy lại trước khi publish.
