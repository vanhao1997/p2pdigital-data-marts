---
title: Kiểm soát output
description: Chọn cột, filter và giới hạn dữ liệu được xuất.
---

Output controls xác định field nào được publish hoặc gửi tới destination. Dùng filter để giảm dữ liệu không cần thiết, giới hạn row để tránh vượt quota, và kiểm tra timezone của field ngày. Sau khi thay đổi output controls, chạy preview rồi publish lại nếu schema thay đổi.
