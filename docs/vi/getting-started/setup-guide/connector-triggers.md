---
title: Connector triggers
description: Lên lịch đồng bộ dữ liệu từ connector.
---

Mở **Triggers → Connector run**, chọn lịch và timezone, rồi lưu. Đảm bảo connector trigger chạy trước report trigger đủ lâu để dữ liệu hoàn tất. Khi nhận rate limit hoặc timeout, giảm tần suất, kiểm tra quota provider và retry theo Run History.
