---
title: Data Mart theo pattern
description: Tạo Data Mart từ pattern được định nghĩa sẵn.
---

Pattern giúp chuẩn hóa tên cột, filter và cách phân trang giữa nhiều project. Chọn pattern phù hợp, điền các tham số bắt buộc, preview kết quả rồi lưu. Không dùng pattern nếu provider chưa được cấp credential hoặc pattern đang ở phiên bản cũ.
